# DL_market

Forecasting vs reinforcement learning for crypto allocation. Models are written from
scratch in JAX and PyTorch.

Research question: does an auxiliary return-forecasting loss improve a GRU-based PPO
trading policy on hourly BTC data, out of sample and after trading costs?

This is a historical simulation for research and learning. It is not trading advice
and places no real orders.

Status: project scaffold only.
